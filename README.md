# INCURSION — Marvel Problem-Solving Hackathon

A cinematic, responsive landing page concept for the GeeksForGeeks × Bennett University Marvel-themed 24-hour hackathon.

## Tech Stack
- HTML5
- CSS3 (custom animations, responsive layouts, CSS variables)
- Vanilla JavaScript
- Google Fonts
- SVG graphics

## Features
- Animated boot sequence
- Responsive navigation and layouts
- Scroll-triggered reveal animations using IntersectionObserver
- Mouse-parallax hero layer
- Dynamic particle generation
- Live registration countdown
- Reality-shift theme toggle
- Client-side registration form interaction
- Reduced-motion accessibility support

## Run locally
Open `index.html` in any modern browser.
